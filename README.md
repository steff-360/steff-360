#### Desafio Rapido (Haz clic para jugar):

<details>
<summary><b>Mision 1: El Acertijo del Servidor</b> (Haz clic para abrir)</summary>
<br/>

> **Situacion:** Estás en una sala con un servidor Node.js que requiere una clave para abrir la puerta.
> **Pista:** La clave es el método HTTP que se utiliza para actualizar parcialmente un recurso en una API REST.

- A) `GET`
- B) `POST`
- C) `PATCH`

<details>
<summary><i>Verificar respuesta</i></summary>

**Correcto si elegiste C (PATCH).**
`PATCH` se utiliza para modificaciones parciales sin reemplazar todo el documento. Primera cerradura desbloqueada.
</details>

</details>

<details>
<summary><b>Mision 2: El Enigma de la Base de Datos</b> (Haz clic para abrir)</summary>
<br/>

> **Situacion:** Necesitas vincular los datos de dos tablas sin perder ningun jugador que aún no tenga puntaje registrado.

- A) `INNER JOIN`
- B) `LEFT JOIN`
- C) `CROSS JOIN`

<details>
<summary><i>Verificar respuesta</i></summary>

**Correcto si elegiste B (LEFT JOIN).**
`LEFT JOIN` preserva todos los registros de la tabla izquierda aunque no existan coincidencias en la derecha. Alarma desactivada.
</details>

</details>
