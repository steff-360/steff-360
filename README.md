#### Desafío Rápido en el Perfil (Haz clic para jugar):

<details>
<summary>🕹️ <b>Misión 1: El Acertijo del Servidor</b> (Haz clic para abrir el reto)</summary>
<br/>

> **Situación:** Estás atrapada en una sala con un servidor Node.js que requiere una clave para abrir la puerta.  
> **Pista:** La clave es el método HTTP que se utiliza para actualizar parcialmente un recurso en una API REST.

- A) `GET`
- B) `POST`
- C) `PATCH`

<details>
<summary>👁️ <i>Verificar respuesta</i></summary>

**¡Correcto si elegiste la opción C (PATCH)!**  
`PATCH` se utiliza para modificaciones parciales sin reemplazar todo el documento. ¡Has desbloqueado la primera cerradura!
</details>

</details>

<details>
<summary>🕹️ <b>Misión 2: El Enigma de la Base de Datos</b> (Haz clic para abrir el reto)</summary>
<br/>

> **Situación:** Necesitas vincular los datos de dos tablas (`jugadores` y `puntajes`) sin perder ningún jugador que aún no tenga puntaje registrado.

- A) `INNER JOIN`
- B) `LEFT JOIN`
- C) `CROSS JOIN`

<details>
<summary>👁️ <i>Verificar respuesta</i></summary>

**¡Correcto si elegiste la opción B (LEFT JOIN)!**  
`LEFT JOIN` preserva todos los registros de la tabla izquierda aunque no existan coincidencias en la derecha. ¡Has desactivado la alarma del sistema!
</details>

</details>
