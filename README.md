### 🎮 Mini-Juego: Escape the Terminal
> Pon a prueba tu lógica de programación. Haz clic en cada puerta para revelar el enigma y su solución:

<details>
<summary>🚪 <b>Nivel 1: El Desafío de JavaScript</b> (Haz clic para abrir)</summary>

```javascript
// ¿Qué devuelve la desestructuración de este array?
const stack = ["Node.js", "PostgreSQL", "Three.js"];
const [backend, ...others] = stack;

console.log(backend);
```
**Respuesta:** `"Node.js"`  
*Explicación:* La desestructuración toma el primer elemento del array, aislando el núcleo de la arquitectura backend.
</details>

<details>
<summary>🚪 <b>Nivel 2: La Consulta SQL del Sistema</b> (Haz clic para abrir)</summary>

```sql
-- ¿Qué registros filtra esta consulta relacional?
SELECT usuarios.nombre, equipos.nombre_equipo
FROM usuarios
INNER JOIN equipos ON usuarios.equipo_id = equipos.id
WHERE usuarios.activo = TRUE;
```
**Respuesta:** Obtiene los nombres de todos los usuarios activos vinculados a su equipo correspondiente mediante una clave foránea (`INNER JOIN`).
</details>
